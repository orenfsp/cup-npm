Отклик

Отклик — платформа анонимных доверительных обращений для учеников, родителей и педагогов.

Быстрый запуск

Требования:

Docker Desktop / Docker Engine

Docker Compose

Запуск:

docker compose up --build

После запуска:

Сайт заявителя: http://localhost:3000

Вход сотрудников: http://localhost:3000/staff/login

API health: http://localhost:8000/health

Дополнительно устанавливать Node.js, Python, PostgreSQL или Valkey локально не требуется.

Возможности

Заявитель

обращение без регистрации;

выбор типа заявителя и категории;

динамические вопросы;

вложения;

кризисные маркеры и контакты помощи;

трек-номер формата ОТК-XXXX-XXXX;

просмотр статуса;

анонимный диалог со специалистом;

ответы на уточнения;

получение рекомендаций;

сценарии «Это помогло» / «Это не помогло»;

оценка работы.

Оператор

очередь новых и возвращённых обращений;

кризисные и срочные обращения в приоритете;

уточнение категории и приоритета;

подсказка маршрутизации;

назначение специалиста;

отклонение спама с причиной;

подтверждение передачи обращения между специалистами;

обработка возвратов и жалоб.

Эксперт

только назначенные обращения;

перевод обращения в работу;

диалог с заявителем;

запрос уточнения;

внутренние заметки;

соисполнители;

запрос передачи;

действие «Не могу взять обращение»;

итоговые рекомендации.

Администратор

управление сотрудниками;

выдача временных учётных данных;

обязательная смена временного пароля;

управление типами заявителей;

категории и динамические вопросы;

группы специалистов и лимиты нагрузки;

правила маршрутизации;

кризисные маркеры;

ресурсы экстренной помощи;

изменение метаданных зависших обращений с причиной;

журнал аудита;

аналитика за период;

CSV-выгрузка без текстов обращений.

Безопасность и приватность

у заявителя нет аккаунта;

имя, email, телефон и учебное заведение не требуются по умолчанию;

трек-номер в открытом виде не хранится;

чувствительные данные шифруются AES-256-GCM;

пароли сотрудников хранятся как Argon2-хэши;

временный пароль показывается администратору только один раз;

роли и доступы проверяются на сервере;

администратор не читает тексты обращений, чаты, заметки и вложения;

оператор после назначения не читает диалог заявителя со специалистом;

аналитика и CSV используют только метаданные;

сторонние аналитические трекеры не используются.

Быстрая демонстрация

Откройте http://localhost:3000 и создайте обращение.

Сохраните трек-номер.

Войдите как demo_operator и назначьте специалиста.

Войдите как demo_expert, возьмите обращение в работу и задайте уточняющий вопрос.

Откройте обращение по трек-номеру и ответьте.

Подготовьте рекомендации от имени эксперта.

Проверьте ветку «Это помогло» или «Это не помогло».

Войдите как demo_admin и проверьте категории, маршрутизацию, аналитику, аудит и CSV.

C8 — Аналитика

Метрики за период → нагрузка → доля возвратов → CSV без текстов обращений.
